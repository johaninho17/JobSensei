# Agy commands

Type these in the Agy panel (Chat or Console). `/help` always shows the full current list.

| Command | What it does |
|---|---|
| `/help` | Shows the available commands and keyboard shortcuts |
| `/model` | Picks the model Agy uses (`/model <name>` for one prompt on another model) |
| `/effort` | Sets how hard Agy thinks: lower is faster and uses less quota, higher is more careful |
| `/usage` | Shows how much of your quota is left |
| `/config` | Opens Agy's settings, including its colour scheme |
| `/resume` | Opens an earlier conversation<!-- feature:candidates --> (only the open candidate's)<!-- /feature --> |
| `/clear` | Starts a fresh conversation (useful between jobs) |
| `/skills` | Lists the skills Agy has (JobSensei's come with the app) |
| `/permissions` | Shows what Agy may do. JobSensei sets these for you; leave them as they are |
| `/agents` | Lists custom agents |
| `/plugin` | Manages Agy plugins |
| `/hooks` | Manages Agy hooks |
| `/changelog` | Shows what changed in Agy |
| `/credits` | Shows your remaining credits |

## Tips

- **Quota running low:** lower `/effort`, or wait for it to reset (`/usage` shows when).
- **A slow or confused run:** `/clear`, then send the job again from the job's ⋯ menu.
- **JobSensei's instructions:** the app keeps Agy's skills up to date each time Agy starts; you don't need to install anything.
