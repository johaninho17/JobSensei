# JobSensei Challenge

## Description

Create hands-on practice for one existing job's explicitly confirmed technical challenge, coding test, take-home, or implementation assessment.

## Steps

1. Invoke `$jobsensei-technical-challenge` with the company, assessment format, and any known constraints from the user's prompt.
2. Resolve exactly one existing job workspace. Stop rather than creating a new job or reading sibling jobs.
3. Prefer an actual supplied prompt, then interviewer-reported process, then official guidance. Label inferred exercises as practice approximations.
4. Create only `challenge_brief.md`, `practice_labs.json`, and `challenge.json` in one requested challenge round.
5. Register the challenge artifacts in `interviews/interview.json` without modifying existing application or interview-preparation artifacts.
6. Stop after the practice artifacts are ready. Do not begin a mock, advance another round, or write an employer submission.
